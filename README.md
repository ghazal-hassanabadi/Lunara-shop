# لونارا (Lunara) | فروشگاه آنلاین پوشاک زنانه

لونارا یک مینی‌فروشگاه فارسی و راست‌چین برای پوشاک زنانه است (صفحه‌ی اصلی + صفحه‌ی فروشگاه). این پروژه را برای تسک **ساخت مینی‌فروشگاه** نوشته‌ام: نمایش محصولات، جستجوی لحظه‌ای و سبد خرید با ذخیره در `localStorage`.

🔗 **مشاهده‌ی خروجی پروژه:** `https://ghazal-hassanabadi.github.io/Lunara-shop/ `

---

## سایت چیست و چه کاری می‌کند؟

### صفحه‌ی اصلی (`index.html`)

صفحه‌ی معرفی فروشگاه است و کاربر می‌تواند کالکشن‌ها را ببیند، دسته‌بندی‌ها را مرور کند و پرفروش‌ترین محصولات را به سبد خرید اضافه کند.

- **نوار اعلان:** اطلاعات ارسال و ارسال رایگان.
- **هدر:** لوگو، منوی اصلی، کادر جستجو و آیکون‌های حساب کاربری، علاقه‌مندی‌ها و سبد خرید (با شمارنده‌ی تعداد).
- **اسلایدر اصلی (Hero):** سه اسلاید که خودکار عوض می‌شوند، با نقطه‌های قابل کلیک و دکمه‌ی «مشاهده محصولات».
- **دسته‌بندی‌ها:** پالتو، بارانی، هودی، بافت و شلوار با کارت‌های گرد.
- **پرفروش‌ترین‌ها:** چهار محصول اول از لیست محصولات + بنر تخفیف زمستانه.
- **مزایای خرید:** ارسال سریع، پرداخت امن، بازگشت کالا و پشتیبانی.
- **اینستاگرام و فوتر.**

### صفحه‌ی فروشگاه (`product.html`)

- لیست کامل محصولات به‌صورت کارت (عکس، نام، قیمت، قیمت قبلی خط‌خورده و برچسب درصد تخفیف).
- **جستجوی لحظه‌ای:** همزمان با تایپ، لیست فیلتر می‌شود. اگر چیزی پیدا نشود پیام «محصولی پیدا نشد» نمایش داده می‌شود.
- فرم فیلتر (دسته‌بندی، محدوده‌ی قیمت، فقط تخفیف‌دارها) که فعلاً فقط ظاهر آن آماده است (بخش «کارهای آینده» را ببینید).

### سبد خرید

1. با کلیک روی «افزودن به سبد خرید»، اطلاعات محصول از روی کارت خوانده می‌شود.
2. اگر محصول از قبل در سبد باشد، ردیف جدید ساخته **نمی‌شود** و فقط `qty` آن یکی زیاد می‌شود.
3. سبد در `localStorage` ذخیره می‌شود، پس با رفرش یا بستن صفحه از بین نمی‌رود.
4. عدد کنار آیکون سبد در هدر، مجموع تعداد کالاها را با عدد فارسی نشان می‌دهد.

سایت **ریسپانسیو** است و برای زبان فارسی با `dir="rtl"` و فونت Vazirmatn طراحی شده است.

## تکنولوژی‌ها

- HTML5 (تگ‌های معنایی مثل `article`، `figure`، `data`، `del`)
- Tailwind CSS
- JavaScript خام با ES Modules
- `localStorage`


### تنظیمات Tailwind

رنگ‌های برند در تنظیمات Tailwind تعریف شده‌اند و با کلاس‌هایی مثل `bg-wine` و `text-ink` در کل پروژه استفاده می‌شوند:

| نام رنگ | کاربرد |
|---|---|
| wine | رنگ اصلی برند (دکمه‌ها، برچسب‌ها، فوتر) |
| cream | پس‌زمینه‌ی صفحه |
| sand | پس‌زمینه‌ی کارت‌ها و کادرها |
| ink | رنگ متن |

## اجرای پروژه

چون از ES Modules استفاده شده، باز کردن مستقیم `index.html` کار نمی‌کند و باید با سرور محلی اجرا شود:

```bash
npx serve
# یا افزونه‌ی Live Server در VS Code
```

اگر کلاس‌های Tailwind را تغییر دادید:

```bash
npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch
```

## نحوه‌ی کار JavaScript

**جریان داده:** `products.js` ← `render.js` ← `main.js`

### `main.js`
عنصر `#products-list` را پیدا می‌کند. اگر وجود داشت، مقدار `data-limit` را می‌خواند (۴ در صفحه‌ی اصلی، و در صفحه‌ی فروشگاه بدون محدودیت) و محصولات را رندر می‌کند. بعد `initSlider`، `initSearch` و `initCart` را اجرا می‌کند.

### `products.js`
آرایه‌ای از ۸ محصول با `id`، `name`، `price`، `oldPrice`، `discount`، `image` و `category`. چون استفاده از API اختیاری بود، داده را دستی نوشتم. برای افزودن محصول جدید فقط یک آبجکت به این لیست اضافه می‌شود.

### `render.js`
تابع `createCard` از روی داده‌ی هر محصول یک کارت HTML می‌سازد. برچسب تخفیف و قیمت خط‌خورده فقط وقتی نمایش داده می‌شوند که محصول `oldPrice` و `discount` داشته باشد. قیمت‌ها با `toLocaleString("fa-IR")` به عدد فارسی و سه‌رقمی فرمت می‌شوند. یک کد برای هر دو صفحه استفاده شده است.

### `search.js`
- **صفحه‌ی فروشگاه:** با رویداد `input` نام محصولات فیلتر و دوباره رندر می‌شود.
- **صفحه‌ی اصلی:** با زدن اینتر، کاربر به `product.html?q=...` می‌رود و صفحه‌ی فروشگاه عبارت را از آدرس می‌خواند و جستجو را اعمال می‌کند.

### `slider.js`
با `setInterval` هر چند ثانیه عکس و متن اسلاید عوض می‌شود. با نقطه‌ها می‌شود دستی جابه‌جا شد، با رفتن موس روی اسلایدر متوقف می‌شود و با خروج دوباره شروع می‌شود. عکس‌ها از قبل (`new Image()`) بارگذاری می‌شوند تا تغییر اسلاید تأخیر نداشته باشد.

### `cart.js`
سبد خرید با **event delegation** روی کل `document` کار می‌کند؛ یعنی یک شنونده‌ی کلیک برای همه‌ی دکمه‌ها، حتی کارت‌هایی که بعداً با JavaScript ساخته می‌شوند.

```js
const existing = cart.find((item) => item.id === product.id);
if (existing) existing.qty += 1;
else cart.push({ ...product, qty: 1 });
```

خواندن از `localStorage` داخل `try/catch` است تا اگر داده خراب بود برنامه کرش نکند و سبد خالی برگردد.

از هوش مصنوعی برای کمک در رفع باگ‌ها (مثلاً تأخیر در تغییر اسلاید، استایل دکمه‌ها) و مرور کد استفاده کردم. منطق هر بخش را بررسی کرده‌ام و می‌توانم توضیح بدهم.

## کارهای آینده (اگر ۲ ساعت دیگر وقت داشتم)

- ساخت **صفحه‌ی سبد خرید** با افزایش/کاهش تعداد، حذف محصول و جمع کل.
- نوشتن منطق **فیلتر** (دسته‌بندی، محدوده‌ی قیمت، تخفیف). فرم آن در `product.html` آماده است و فقط JavaScript آن مانده.
- فعال کردن **منوی موبایل** (دکمه‌ی همبرگری فعلاً فقط ظاهر دارد).
- دریافت محصولات از `fakestoreapi.com` با `fetch` و نمایش حالت لودینگ و خطا.
- ذخیره‌ی **علاقه‌مندی‌ها** در `localStorage`.
- **debounce** برای جستجو.
